# 视频合成功能 · 演示优化需求文档

> 状态：待评审（功能层）。本文只描述"做成什么样"，不涉及代码改动方案。评审通过后再出《技术改动文档》。
> 适用范围：CanvasFlow 演示仓库。

---

## 一、背景与目标

当前"时间轴"功能在画布上以一个超大节点的形式直接展开整个多轨编辑器，节点命名、连接方式、编辑器形态都与目标演示效果不一致。本次优化把它重构为更接近真实产品的两层结构：

- **画布层**：一个轻量的"视频合成"卡片节点，多段视频从左侧汇入。
- **编辑层**：点击卡片后打开的全屏编辑页（预览 + 单视频轨 + 工具栏）。

目标是让演示流程顺畅、视觉与交互贴合截图。

## 三、详细需求

### R1 · 添加节点面板（截图1）

- 把"添加节点"面板里原来的 **"时间轴"** 项改名为 **"视频合成"**，并保留 `Beta` 标识（截图1 显示为 `Beta`，当前代码里是 `NEW`，需确认统一成哪个）。
- 副标题改为贴合"合成"语义，建议：**"多个视频片段合为一个"**（同截图1）。
- 图标改为剪刀(✂)类图标（截图1）。
- **位置**：放在"视频"项下方，作为添加节点列表里的一项，紧跟在 文本 / 图片 / 视频 之后。（当前它单独在"组装"分组里，需要并入主节点列表、紧贴"视频"。）

### R2 · 画布连接方式（截图2）

- **删除视频节点底部的连接点**（当前橙色"底部 → 时间轴"端口）。
- 所有连接**统一只走左右**：视频片段从节点**右侧**输出，连入"视频合成"节点**左侧**的输入端口。
- 多段视频（如示例的 3 段）各拉一条线，**统一汇入"视频合成"节点左侧**。
  - 待确认：左侧是**单个输入端口**承接多条连线，还是每段一个端口。建议单端口（更简洁，贴合截图2 三线汇聚到左侧一点的观感）。
- 视频合成节点的**输出端口仍在右侧**（保持可继续往后接的能力）。

### R3 · 画布上的"视频合成"节点形态（截图2）

- 画布节点不再内嵌完整编辑器，改为一个**紧凑卡片**：
  - 标题：如 `视频合成 2`。
  - 卡片主体显示一个**预览缩略图**（建议取合成结果/第一段画面）。
  - 卡片中央或底部有 **"打开视频合成"** 按钮/入口。
- 点击"打开视频合成" → 打开 R4 的全屏编辑页。
- 待确认：卡片上是否还要显示"已连接 N 段 / 总时长"等信息。

### R4 · 全屏视频合成编辑页 · 整体布局（截图3）

进入后是一个覆盖全屏的编辑页：

- **顶部栏**：左上角标题"视频合成"；右上角 **导出**（带下拉）按钮 + **关闭(✕)** 按钮。
- **上半部：预览区**，居中显示当前播放头所在画面。
- **下半部：时间轴区**，关键简化点——**只有一条视频轨**（按顺序排列各视频片段，带缩略图与每段时长，如 `视频节点4 00:00:05:21`）。
  - 说明：**移除当前实现里的 V2 叠加、画面增强、A1 背景音乐等多轨演示内容**，编辑页聚焦单条视频轨。（需确认是否同意精简。）
- 时间轴上方有播放头与时间刻度（00:00、00:01 …）。
- 时间轴左侧工具按钮区见 R5/R6。
- 播放控制见 R7，右侧缩放控制见 R8。

### R5 · 工具栏（未选中任何片段时）（截图4）

当只有时间轴/播放头、**没有选中具体片段**时，工具从左到右为：

1. **撤销**
2. **前进**（重做）
3. **分割**
4. **向右裁剪**
5. **向左裁剪**

- 此时**没有"变速"工具**（或置灰不可点）。
- 待确认：分割/向右裁剪/向左裁剪在"未选中片段"时的作用对象——通常以**播放头位置**为基准对播放头所在片段进行操作。请确认语义：
  - 分割 = 在播放头处把当前片段切成两段；
  - 向右裁剪 = 裁掉播放头右侧部分；
  - 向左裁剪 = 裁掉播放头左侧部分。

### R6 · 选中片段 + 变速（截图4、5）

- 用户点击某个视频片段后，该片段进入**选中态**（高亮/描边）。
- 选中后工具栏出现第六个图标 **变速**（截图4 最右侧的图标）。
- 点击"变速"弹出**变速面板**（截图5）：
  - **倍数**：滑杆 + 数值（如 `1.00x`），截图显示约 5 个档位点（建议档位：0.5x / 1x / 2x / 4x …，需确认）。
  - **时长**：滑杆 + 数值（如 `5.7s`）。
  - **联动规则**：倍数与时长**反向联动**——倍数变大→时长变短，倍数变小→时长变长（基于该片段原始时长换算）。两者任意一侧调整，另一侧自动更新。
- 变速面板必须在**有片段被选中**时才可用。

### R7 · 播放与全屏预览（截图6、7）

- 时间轴上方中部有两个控制（截图6）：
  - **播放/暂停**；
  - **全屏预览**。
- 点击全屏预览 → 进入**全屏播放视图**（截图7）：画面铺满，底部一条播放进度条 + 当前时间 / 总时长。
- 全屏视图**右下角有退出按钮**，点击返回编辑页。

### R8 · 缩放与收缩控制（截图8）

时间轴右下角三个图标，从左到右：

1. **缩小镜**：每点一次，整条时间轴变得更紧凑，更容易看到全局。
2. **放大镜**：每点一次，逐帧放大，时间轴变长、可看清细节。
3. **收缩 icon**：点击后切换到"收缩态视图"（见 R9）。

### R9 · 收缩态视图（截图9、10）

- 点击 R8 的收缩 icon 后，编辑页**收起**为一种可同时看到**外部画布**的形态（截图9）：
  - 预览画面缩为左上角的小窗；
  - 视频合成卡片回到画布上；
  - 下方仍保留时间轴轨道用于编辑。
- 此时右下角的那组控制图标**变化为**（截图10）：
  1. **展开预览（占满时间轴上方）**：点击后预览重新铺满时间轴上方区域（即回到 R4 的展开形态）。
  2. **✕ 退出剪辑**：点击后完全退出编辑，回到画布。

## 四、状态与交互流转（小结）

```
画布
 └─[添加节点]→ 视频合成节点(小卡片, 左入右出)
        └─[点击"打开视频合成"]→ 全屏编辑页(R4)
                ├─ 未选中片段 → 工具: 撤销/前进/分割/右裁/左裁 (R5)
                ├─ 选中片段   → 追加"变速"工具 → 变速面板(倍数↔时长) (R6)
                ├─ 播放 / 全屏预览(R7) → 全屏播放页 → 右下角退出
                ├─ 缩小/放大(R8)
                └─ 收缩(R8) → 收缩态视图(R9) → 展开预览 / 退出剪辑(R10图标)
```
