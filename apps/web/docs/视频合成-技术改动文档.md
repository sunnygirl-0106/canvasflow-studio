## 1. 数据结构改动（`store/canvasStore.ts`）

### 1.1 节点类型重命名
```ts
// 旧
export type NodeKind = "image" | "generateImage" | "generateVideo" | "timeline";
// 新
export type NodeKind = "image" | "generateImage" | "generateVideo" | "composition";
```
全局把 `"timeline"` 替换为 `"composition"`，相关命名（`timelineCount` 等）一并改为 `compositionCount`。中文展示名用「视频合成」。

### 1.2 Shot 增加变速字段
```ts
export interface Shot {
  id: string;
  name: string;
  index: number;
  duration: number;     // 当前时长(随变速变化)
  baseDuration: number; // 新增：原始时长，用于 时长 = baseDuration / speed 换算
  speed: number;        // 新增：倍数，默认 1
  thumbnail?: string;
  color: Shot["color"];
  // sourceIn/sourceOut/bindings/status 可保留或删除（单轨简化后非必需）
}
```

### 1.3 新增"编辑页"状态（放进 store，组件内只放纯 UI 局部态）
```ts
interface State {
  // ...原有
  editorCompId: string | null;        // 当前打开的视频合成节点 id；null=未打开
  editorMode: "full" | "collapsed";   // 展开 / 收缩态
  selectedClipId: string | null;      // 编辑页内选中的片段
  openComposition: (id: string) => void;
  closeComposition: () => void;        // 退出剪辑
  setEditorMode: (m: "full" | "collapsed") => void;
  selectClip: (id: string | null) => void;
  // 片段操作
  splitClip: (compId: string, clipId: string, atSec: number) => void;
  cropClip: (compId: string, clipId: string, side: "left" | "right", atSec: number) => void;
  setClipSpeed: (compId: string, clipId: string, speed: number) => void;
}
```
> 播放头时间、缩放(pxPerSec)、全屏播放开关 这类纯视觉态建议放编辑页组件 `useState`，不进 store。

### 1.4 连接逻辑改为左右
- `mergeSelectionToTimeline` / `addNodeToTimeline`（建议改名 `mergeToComposition` / `addToComposition`）里：
  - 生成的 `Edge` 把 `sourceHandle: "source-timeline"`（底部）改为 **`sourceHandle: "source-process"`（视频节点右侧出口）**。
  - `toHandle` 从"每个 shot 一个顶部端口"改为 **统一指向合成节点左侧单一输入端口**（如 `toHandle: "comp-in"`）。
- 合成节点新位置：放在所选素材**右侧**（`x = maxX + 偏移`，纵向居中），不再放下方。

## 5. 全屏视频合成编辑页（新建目录 `components/composition/`）· R4–R9

挂载位置：在 `routes/index.tsx` 的 `Workspace` 里，根据 `editorCompId` 条件渲染 `<CompositionEditor />`（用 `createPortal` 到 body，全屏覆盖）。

建议组件拆分：
```
components/composition/
  CompositionEditor.tsx   // 容器：根据 editorMode 切换 full/collapsed 布局
  EditorTopBar.tsx        // 标题 + 导出(下拉) + 关闭✕            (R4)
  PreviewStage.tsx        // 预览画面(取当前播放头所在片段缩略图)   (R4/R7)
  PlaybackControls.tsx    // 播放/暂停 + 全屏预览                  (R6/R7)
  TrackTimeline.tsx       // 单视频轨：刻度 + 片段 + 播放头         (R4/R5/R6)
  EditorToolbar.tsx       // 撤销/前进/分割/右裁/左裁 (+变速)       (R5/R6)
  SpeedPanel.tsx          // 变速面板(倍数↔时长联动)               (R6)
  ZoomControls.tsx        // 缩小/放大/收缩 | 展开预览/退出剪辑     (R8/R9)
  FullscreenPlayer.tsx    // 全屏播放页(进度条 + 右下角退出)        (R7)
```

### 5.1 单视频轨 `TrackTimeline` · R4
- 只渲染**一条**视频轨（移除原 V2 叠加 / 画面增强 / A1 音频）。
- 片段按顺序排布，宽度 = `duration * pxPerSec`，显示缩略图 + `名称 时长`。
- 顶部时间刻度 + 可拖拽红色播放头（逻辑可从旧 `TimelineNode` 的 `handlePlayheadDrag` / `layoutShots` / 拖拽排序 / 左右裁剪 resize 迁移复用）。
- `pxPerSec` 由 `ZoomControls` 控制（见 5.5）。

### 5.2 工具栏 · R5/R6（`EditorToolbar`）
未选中片段（`selectedClipId === null`）时，从左到右：
1. 撤销 → `undo()`
2. 前进 → `redo()`
3. 分割 → `splitClip(compId, 播放头所在片段, playheadSec)`
4. 向右裁剪 → `cropClip(..., "right", playheadSec)`
5. 向左裁剪 → `cropClip(..., "left", playheadSec)`

选中某片段后，额外出现第 6 个图标 **变速**，点击打开 `SpeedPanel`。未选中时该图标隐藏或置灰。

> 片段操作语义（以播放头为基准）：
> - split：在 `atSec` 处把片段切成两段；
> - crop right：保留播放头左侧，裁掉右侧；
> - crop left：保留播放头右侧，裁掉左侧。

### 5.3 变速面板 · R6（`SpeedPanel`）
- 仅当有选中片段时可用。
- 倍数滑杆（档位 `0.5 / 1 / 2 / 3 / 4`，默认 1.00x）+ 数值。
- 时长滑杆 + 数值。
- 联动：`duration = baseDuration / speed`；调倍数自动算时长，调时长反算倍数。统一走 `setClipSpeed`（内部据 baseDuration 重算 duration）。

### 5.4 播放 / 全屏预览 · R7
- `PlaybackControls`：播放/暂停（推进播放头，逻辑同旧节点的 `setInterval`）、全屏预览按钮。
- 全屏预览 → 渲染 `FullscreenPlayer`（画面铺满 + 底部进度条/时间 + 右下角退出按钮）。

### 5.5 缩放 + 收缩 · R8（`ZoomControls`）
- 缩小：`pxPerSec = max(min, pxPerSec * 0.8)`（轴更紧凑）。
- 放大：`pxPerSec = pxPerSec * 1.25`（轴更长、逐帧）。
- 收缩 icon → `setEditorMode("collapsed")`。

### 5.6 收缩态视图 · R9
- `editorMode === "collapsed"` 时，`CompositionEditor` 改为：底部保留时间轴 + 工具，预览缩成左上角小窗，**露出后面的画布**（即编辑页背景透明/只占下半部）。
- 此时 `ZoomControls` 右侧那组图标替换为：
  1. 展开预览（占满时间轴上方）→ `setEditorMode("full")`
  2. ✕ 退出剪辑 → `closeComposition()`

## 7. 建议实施顺序（分 5 步，每步可独立验证）

1. **store 重构**：重命名 `timeline→composition`、Shot 加 `speed/baseDuration`、加编辑页状态与片段操作 action。
2. **画布层小改**：`AddNodePanel`(R1) + `GenerateVideoNode` 删底部点(R2) + `index.tsx` 连接逻辑改左右。
3. **画布卡片**：新建 `CompositionNode`(R3)，替换 nodeTypes 里的 `timeline`，删 `TimelineNode`。
4. **全屏编辑页**：搭 `CompositionEditor` 骨架 + 顶栏/预览/单轨/播放头(R4)，迁移旧节点里可复用的布局与拖拽逻辑。
5. **编辑页交互**：工具栏(R5)+选中/变速(R6)+全屏播放(R7)+缩放(R8)+收缩态(R9)。

每步后 `bun dev` 跑一遍，确认画布外观未回退、连接线为左右、编辑页各态可切换。
